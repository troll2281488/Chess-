# Chess

Адаптивные браузерные шахматы на русском языке. Статический сайт для GitHub Pages — сборка не требуется.

## Возможности
- Шахматные правила и легальные ходы на базе chess.js.
- Игра против локального бота с несколькими уровнями сложности (эвристический бот, не Stockfish).
- Онлайн-комнаты через Firebase Realtime Database и анонимную авторизацию.
- Адаптивная доска, подсветка ходов, история, переворот доски и звук.
- Экономный сетевой обмен: подписка на одну комнату, без аналитики и постоянного опроса.

## Публикация
GitHub Pages: https://troll2281488.github.io/Chess-/

В репозитории откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**. Сохраните настройки. Главная страница находится в `index.html`.

## Firebase
Проект использует Firebase project `klik-e2780`.
1. В Firebase Console включите **Authentication → Sign-in method → Anonymous**.
2. Создайте/проверьте Realtime Database.
3. В **Realtime Database → Rules** примените правила из `database.rules.json`.
4. Проверьте, что URL базы совпадает с `databaseURL` в конфигурации `index.html`.

## Безопасность и ограничения
Firebase Web API key в клиентском приложении не является секретом. Доступ к данным ограничивайте правилами базы. Предложенные правила ограничивают доступ участниками комнаты, но не проверяют легальность шахматных ходов. Для честной соревновательной игры нужна серверная проверка ходов (например, Cloud Functions). Не размещайте в клиентском коде секретные ключи.
