# Chess

Адаптивные браузерные шахматы на русском языке. Статический сайт для GitHub Pages — сборка не требуется.

## Возможности
- Новое лобби с отдельными вкладками: главная, игра, онлайн и настройки.
- Игра против локального бота с несколькими уровнями сложности (эвристический бот, не Stockfish).
- Быстрая онлайн-игра с поиском соперника через очередь Firebase.
- Приватные комнаты: создание лобби, шестизначный код приглашения и подключение по коду.
- Шахматные правила и легальные ходы на базе chess.js.
- Адаптивная доска, подсветка возможных ходов, история, переворот доски и звуки.
- Анонимная авторизация Firebase; обмен состоянием партии через Realtime Database.

## Публикация
GitHub Pages: https://troll2281488.github.io/Chess-/

В репозитории откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**. Главная страница находится в `index.html`. После коммита GitHub Pages обычно обновляет сайт автоматически, но публикация может занять несколько минут.

## Firebase
Проект использует Firebase project `klik-e2780`.
1. В Firebase Console включите **Authentication → Sign-in method → Anonymous**.
2. Создайте/проверьте Realtime Database.
3. В **Realtime Database → Rules** полностью замените текущие правила содержимым файла `database.rules.json` из этого репозитория и нажмите **Publish**.
4. Проверьте, что URL базы совпадает с `databaseURL` в конфигурации `index.html`.

Правила дают авторизованным пользователям возможность читать список комнат для присоединения и очередь быстрой игры. Изменять собственную запись в `quickQueue` может только соответствующий анонимный пользователь. Доступ к комнатам ограничен аутентифицированными пользователями; изменения состояния комнаты разрешены её участникам, а присоединение второго игрока — пока место свободно.

## Безопасность и ограничения
Firebase Web API key в клиентском приложении не является секретом. Правила базы ограничивают запись, но не выполняют серверную проверку легальности ходов и не защищают от нечестного клиента, который подменяет FEN. Для рейтинговой/соревновательной игры нужна серверная проверка ходов (например, Cloud Functions). Не размещайте в клиентском коде секретные ключи.
